- ক্লাস এবং অবজেক্ট C++ প্রোগ্রামিং ভাষার দুটি গুরুত্বপূর্ণ ধারণা, যা অবজেক্ট-ওরিয়েন্টেড প্রোগ্রামিং (OOP) এর মূল ভিত্তি।

ক্লাস (Class)
ক্লাস হলো একটি টেমপ্লেট বা ব্লুপ্রিন্ট যা এক বা একাধিক অবজেক্ট তৈরির জন্য ব্যবহার করা হয়। এটি ডেটা মেম্বার (ভেরিয়েবল) এবং মেম্বার ফাংশন (মেথড) এর সংমিশ্রণ।

উদাহরণ: ধরা যাক, আপনি একটি "Student" নামক ক্লাস তৈরি করেছেন।

class Student {
public:  // অ্যাক্সেস স্পেসিফায়ার
    string name;  // ডেটা মেম্বার
    int age;

    void display() {  // মেম্বার ফাংশন
        cout << "Name: " << name << ", Age: " << age << endl;
    }
};


অবজেক্ট (Object):অবজেক্ট হলো ক্লাস থেকে তৈরি হওয়া একটি নির্দিষ্ট ইনস্ট্যান্স। একেকটি অবজেক্ট আলাদা ডেটা ধারণ করে।

উদাহরণ:"Student" ক্লাস থেকে অবজেক্ট তৈরি করা:

int main() {

    Student s1;  // অবজেক্ট তৈরি
    s1.name = "Rahim";
    s1.age = 20;

    s1.display();  // মেম্বার ফাংশন কল করা
}

ক্লাস এবং অবজেক্ট-এর সম্পর্ক
ক্লাস হলো অবজেক্ট তৈরির নকশা বা কাঠামো।
অবজেক্ট হলো ক্লাসের একটি বাস্তব রূপ।
সংক্ষিপ্তভাবে :-
ক্লাস: ডেটা এবং ফাংশনকে একত্রিত করে।
অবজেক্ট: ক্লাসের একটি ইনস্ট্যান্স, যা কার্যকরভাবে ব্যবহার হয়।
এক লাইনে মনে রাখার মতো:

ক্লাস: "কীভাবে অবজেক্ট কাজ করবে" এর পরিকল্পনা।
অবজেক্ট: সেই পরিকল্পনার বাস্তবায়ন।
