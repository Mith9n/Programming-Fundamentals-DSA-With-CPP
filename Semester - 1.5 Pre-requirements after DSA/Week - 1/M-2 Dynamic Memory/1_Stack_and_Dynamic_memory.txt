-Stack Memory বর্ণনা:স্ট্যাক মেমোরি এমন একটি মেমোরি এলাকা যেখানে কম্পাইল টাইমে ভেরিয়েবল তৈরি এবং মুছে ফেলা হয়।
এটি সাধারণত লাস্ট ইন, ফার্স্ট আউট (LIFO) পদ্ধতিতে কাজ করে।
বৈশিষ্ট্য:মেমোরি অটোমেটিক্যালি অ্যালোকেটেড এবং ডিলোকেটেড হয়।
ছোট মেমোরি স্পেস থাকে।
দ্রুতগতিতে কাজ করে কারণ মেমোরি ম্যানেজমেন্ট ম্যানুয়ালি করতে হয় না।
ব্যবহার:
১. লোকাল ভেরিয়েবল
২. ফাংশনের আর্গুমেন্ট

#include <iostream>
using namespace std;

int main() {
    int a = 10;  // Stack memory-তে সংরক্ষিত
    int b = 20;
    cout << "Sum: " << a + b;
}


- Dynamic Memory বর্ণনা:ডাইনামিক মেমোরি রন্টাইমে ম্যানেজ করা হয়। যখন কোড রান করে তখন মেমোরি অ্যালোকেট বা ডিলোকেট করা হয়।
বৈশিষ্ট্য:মেমোরি ম্যানুয়ালি অ্যালোকেট এবং ডিলোকেট করতে হয়।
বড় মেমোরি স্পেস ব্যবহার করা যায়।
যদি ভুলে ডিলোকেট না করা হয়, তবে মেমোরি লিক হতে পারে।
ব্যবহার:
১. ডাটা স্ট্রাকচার যেমন লিঙ্কড লিস্ট, ট্রি ইত্যাদি।
২. যখন মেমোরি সাইজ প্রাথমিকভাবে নির্ধারিত নয়।

#include <iostream>
using namespace std;

int main() {
    int* ptr = new int;  // Dynamic memory allocation
    *ptr = 50;
    cout << "Value: " << *ptr << endl;
    delete ptr;  // Memory deallocation
}
