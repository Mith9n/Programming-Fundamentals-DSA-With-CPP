Dynamic Variable-এর বৈশিষ্ট্য :- 

Runtime মেমোরি অ্যালোকেশন: প্রোগ্রাম চলাকালীন সময়ে নতুন মেমোরি ব্লক তৈরি হয়।
Flexible: আপনি যতটুকু মেমোরি প্রয়োজন ততটুকু নিতে পারবেন, আগে থেকে নির্ধারণ করা লাগে না।
Heap Memory ব্যবহৃত হয়: ডাইনামিক ভেরিয়েবলগুলো স্ট্যাক মেমোরি ব্যবহার না করে হিপ মেমোরি থেকে মেমোরি নেয়।
Manual Deallocation দরকার: প্রোগ্রামারকে delete বা free ব্যবহার করে মেমোরি ডিলোকেট করতে হয়। নাহলে মেমোরি লিক হতে পারে।

Dynamic Variable তৈরি করার Syntax (C++):-

 ------------------------------------------
| data_type* pointer_name = new data_type; |
 ------------------------------------------


new কীওয়ার্ড: মেমোরি অ্যালোকেট করে।
pointer_name: হিপ মেমোরির অ্যাড্রেস রাখে।
delete কীওয়ার্ড: মেমোরি ডিলোকেট করে।



Dynamic Variable তৈরি করা :-

#include <iostream>
using namespace std;
int main() {
    int* ptr = new int;  // Dynamic variable তৈরি
    *ptr = 42;  // ডাইনামিক ভেরিয়েবলে ভ্যালু সংরক্ষণ
    cout << "Dynamic Variable Value: "<< *ptr << endl;

    delete ptr;  // মেমোরি ডিলোকেট
}
