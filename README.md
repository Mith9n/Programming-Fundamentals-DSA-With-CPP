## Overview

This repository serves as a personal knowledge base and portfolio of academic work, tracking progress through core computer science fundamentals. It is organized **module by module**, in the order the topics are typically taught, so any concept can be located and revisited quickly.

**Scope covered:**

- Procedural programming fundamentals in C
- Object-oriented programming in C++
- Complexity analysis
- Linear and non-linear data structures
- Graph algorithms
- Dynamic programming
- Object-oriented programming in Python, including real-world mini projects

> Modules marked with **`*`** in the tables below have been added to close gaps in the original numbering, based on standard curriculum sequencing. Add the corresponding source files locally if they are not yet present.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Mith9n/Programming-Fundamentals-DSA-With-CPP.git
cd Programming-Fundamentals-DSA-With-CPP
```

**Compile and run a C file:**

```bash
gcc filename.c -o output
./output
```

**Compile and run a C++ file:**

```bash
g++ filename.cpp -o output
./output
```

**Run a Python file:**

```bash
python filename.py
```

> Where an `input.txt` file is provided alongside a source file, use it as the program's input for testing.
